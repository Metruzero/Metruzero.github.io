The Website/Portfolio

I've always wanted a website, but the task from ground up always seemed very daunting, lots to learn and do. And I always learn better by simply doing and making iterative progress.

The first step for this website was to grab a template online and iterate on that first. This would allow me to get started immediately and make changes over time and passively learn this over time.

Sidebar and Javascript

One of the first issues I came across working on this was the sidebar. The contents of the sidebar were hardcoded into each page. This immediately created a problem where the amount of work needed to add each project would go up over time, in boring repetitive ways.

Doing some digging online, I found one way that people solve this issue is to have the sidebar html in a seperate file and have some javascript inject that text into each page. The HTML for this worked but unfortunately problems arised because the javascript needed for the sidebar to work wouldn't load.

After some digging, I found this is because the scripts at the end of the html file are loaded asynchronysly. So the sidebar code would be injected before the javascript could be loaded.
